# Excel 训练记录格式

在「历史」页右上角菜单选择「导入 Excel 历史」，可把 `.xlsx` 文件中的过往训练导入当前学员。解析完全在本机进行，导入前会先显示预览，列出新增、已存在和内容有变化的课次；重复导入同一文件不会产生重复课次。

## 工作簿结构

- 训练记录可以放在任意名称的工作表中。只要某个工作表的 A 列出现 `Week 1`、`Week 2` 这类行，就会被识别为训练记录表；其他工作表会被忽略。
- 可选的 `Info` 工作表用于学员资料，见文末。
- 表头使用英文，不区分大小写，允许首尾空白及词间多余空格、换行。`Week`、`Warm-up`、`Cool-down` 仍区分大小写。

## 每节课次的写法

每节课次以一行 `Week N` 开始，下面依次是表头行、热身行（可选）、若干动作行和冷身行（可选）。空行会被跳过，下一个 `Week N` 行开始新的课次。

| 行 | A 列 | B 列 | C–F 列 | G 列 |
|---|---|---|---|---|
| 课次标题 | `Week 1`（N 为周次） | 课次日期 | — | — |
| 表头 | `Exercise` | `Sets` | `Weights` / `Rep range` / `Rep completed` / `Rest` | `Notes` |
| 热身（可选） | `Warm-up` | 热身内容 | — | 热身备注 |
| 动作 | 动作名称 | 组数 | 负重 / 目标次数 / 完成次数 / 组间休息 | 备注 |
| 冷身（可选） | `Cool-down` | 冷身内容 | — | 冷身备注 |

表头行 A–G 列必须依次为 `Exercise, Sets, Weights, Rep range, Rep completed, Rest, Notes`，其中 C 列也接受单数 `Weight`。缺列或顺序错误时，导入会提示工作表和行号。

跨工作表的课次共用连续的 Week 编号。导入时先按 Week 编号合并，再重建日期；同一 Week 内保留原始工作表及行顺序，因此允许一周多次训练。

示例：

| A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| Week 1 | 3/2/2025 | | | | | |
| Exercise | Sets | Weights | Rep range | Rep completed | Rest | Notes |
| Warm-up | Rowing 5 min | | | | | easy |
| Bench press | 3 | 40 | 8-12 | 10 | 90s | |
| DB curl + Plank | 2 | 8each, bw | 12, 30s | 12, 30s | 1min | |
| Cool-down | Stretching | | | | | |

## 课次日期（B 列）

以下写法都可以：

- **Excel 日期单元格**：按表格中的日期导入。
- **文本 `日/月/年`**：例如 `3/2/2025` 表示 2025 年 2 月 3 日；两位年份 `3/2/25` 视为 2025 年。
- **文本 `日/月`**：例如 `3/2`。年份取自前后最近的带年份课次；月份倒退 6 个月或以上时视为跨年。整个文件都没有年份时，最近一节课次记在今年；如果那样会晚于今天，则记在去年。

文本日期一律按「日在前、月在后」理解。若在「月在前」的 Excel 中输入了「日/月」，Excel 可能已把日和月对调存成日期（例如想输入 3 月 2 日的 `2/3`，被存成 2 月 3 日）。导入时会比较两种读法，选择能让课次日期保持先后顺序的一种，这些课次在详情中的「日期来源」显示为「还原」。

日期无法识别或为空时，导入会停止并提示所在行。个别课次日期比上一节早（最多 3 处、每处不超过 30 天）会保留原值并标记为待核对；超出这个范围时导入会停止，请先检查日期列。

## 各列取值

**动作名称（A 列）**：一行一个动作。用「空格 + 空格」连接多个动作即为超级组，例如 `DB curl + Plank`；这时 C、D、E 列可以用逗号为每个动作分别填写，数量须与动作个数一致，否则整格共用。名称含 `drop` 且 C 列为逗号分隔、逐级递减的重量（如 `60, 50, 40`）时，记为递减组。

**组数（B 列）**：1–19 的整数。

**负重（C 列）**：

| 写法 | 含义 |
|---|---|
| `40`、`37.5` | 公斤（动作名含 `sled` 时记为雪橇负重） |
| `30lbs` | 磅，自动换算成公斤 |
| `bw`、`b.w.` | 自重 |
| `6each`、`Single 12` | 单边重量 |
| `Purple`、`2blue`、`light green` | 弹力带颜色及条数 |
| `G+B` | 多条弹力带组合（G/B/O/P/R 为 green/blue/orange/purple/red 缩写，导入后标记待核对） |
| `1red1green` | 器械配重片颜色组合 |
| `Machine`、`Rack 12` | 器械档位 |
| `/` 或留空 | 未记录 |

**目标次数（D 列）与完成次数（E 列）**：

| 写法 | 含义 |
|---|---|
| `10`、`~10` | 固定次数 |
| `8-12` | 次数范围（被 Excel 自动转成日期的范围也能还原） |
| `10, 10` | 单边动作的左、右次数（仅限非超级组） |
| `30s`、`2min` | 时间 |
| `2:23` | 时间（在 Excel 中输入后存为时间格式，按「分:秒」理解） |
| `500m` | 距离 |
| `3round`、`3x10` | 轮数 |
| `/` 或留空 | 未记录 |

**组间休息（F 列）**：`90s`、`90sec` 或 `2min`。

无法识别的负重或次数会原样保留并标记待核对，不会中断导入。名称第一次出现的动作会自动加入动作库，并标记为待核对分类。

## 学员资料（可选 `Info` 工作表）

A 列为标签、B 列为值。可识别的标签：`Name`、`Phone No.`、`Gender`、`Age`、`Height`、`Weight`、`Target`、`Frequency`、`BMR`、`TDEE`、`Habits`、`Medical History`。数值栏可带单位，例如 `172cm`。`Name` 与当前学员或已有学员同名时导入到该学员；否则按这些资料新建学员。没有 `Info` 工作表或 `Name` 为空时，导入到当前学员。
