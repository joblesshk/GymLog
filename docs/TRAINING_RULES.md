## Energy calculation

Estimated activity kcal = `(MET − 1) × 3.5 × body mass kg / 200 × minutes`. This uses the standard resting-MET convention. It does not use a measured individual resting metabolic rate.

| Reference | MET | Software use |
|---|---:|---|
|02054|3.5|Generic classified resistance exercises; per-exercise mapping is approximate.|
|02052|5.0|Squat / hip-hinge category proxy.|
|02024|2.8|Plank name match, light calisthenic category.|
|02058|9.8|Kettlebell / KB swing name match.|
|02022-proxy|3.8|Conditioning category, approximate moderate calisthenic proxy.|
|02035-proxy|5.0|WOD block, approximate moderate circuit proxy.|
|unmapped|none|Unknown classification stays unknown.|

Fixed repetitions assume 3 seconds each; per-side counts are added, ranges use a midpoint, and explicit seconds are used directly. Rest defaults to 60 seconds between positive sets, with shared-block rest apportioned once. Unequal-set combinations are approximate. Activity-average MET values applied to this constructed duration are low-precision estimates; no statistical confidence interval is claimed.

No conversion is made from distance without pace, unknown rounds or machine calories. WOD uses recorded elapsed time where available; fixed-duration completed protocols may use their prescribed time. For Time caps are not expected completion times. WOD energy is shown per block because per-movement elapsed time is unavailable.

Weight uses the most recent valid body metric on or before the session day; only today's session may use an undated starting weight. Saved insight data retains the weight/date used. Missing actuals are not zero. New or copied plans and new rounds start unrecorded. Unrecorded warm-up, cool-down and post-exercise expenditure are excluded.

## Review rules

The model receives structured current records, goal, recent session context and missing-data notes. It must separate observations from uncertainty, avoid cross-unit comparisons and only discuss historical improvement when exercise/load/protocol are comparable. Higher calorie expenditure is not a quality score for strength or hypertrophy.

No posture assessment, injury diagnosis, automatic load increase, fat-loss conversion, dietary compensation or numeric overall score is generated by the application rules. A lack of RPE, duration or technique evidence limits conclusions. ACSM population guidance must not be presented as a prescription for a particular person or medical condition.

Responses use `summary`, `findings`, `suggestions`, `limitations`, `evidenceIDs`. Format, lengths, stream completion and referenced IDs are checked locally. Input fingerprints reject stale responses after data changes. These checks cannot prove clinical or coaching quality; human-reviewed acceptance examples are future work.
